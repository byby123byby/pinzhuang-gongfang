# 拼装工坊家具装配手记

LACK 是家具说明书的视觉基准。IVAR 从同一套页面结构、样式和交互开始。海边小屋保留纸模游戏的独立玩法。

## 设计与内容的交接

| 交接给制作 Agent 的内容 | 来源 |
| --- | --- |
| 纸色、墨蓝、陶土强调色、字标、中文宋体、英文品名斜体、字号、间距、圆角与分隔线 | 直接导入 academy/manual.css |
| 页头、产品信息、开工清单、装配台、右侧步骤、原页缩略图、零件弹窗 | 复用 LACK 或 IVAR 的对应 HTML 结构和类名 |
| 清点后开始、编号跳步、播放与拖动、复位、工具显示、连接特写、选件旋转、查看原图 | 连接现有操作控件和对应步骤数据 |
| 产品名、规格、板件数量、物料编号、准备工具、固定提醒 | 当前货号和版次的产品资料及原图 |
| 安装方式、调节项、条件分支、装配姿态、手和工具的工作点 | 当前说明书的逐步证据。单线产品使用 LACK 流程，多路线产品按 IVAR 的路线控件分流 |
| 产品木色与金属表面、开孔与折边、生成角度及选用网格 | 该产品实际外观和工作面。界面色和装配模型的实物色分别设定 |

## 发布前对照

在同一浏览器、系统字体、缩放比例与窗口宽度下打开基准页及本次说明书。1280 × 840 和 390 × 844 两组视口分别对照开工清单、装配台和零件弹窗。比较公共控件的实际字体、颜色、边框、版心位置、列宽、内边距与响应式布局。判断文案变化按产品内容；固定控件的样式或栏位偏移回到共享样式修复。记录网页截图、差异清单和产品专有控件。

IVAR 的可运行对照检查在 ivar-pilot/verification/verify-visual.py。实际对照基准为本地网站 /lack/。样式修正后重新构建并复测。适配下一产品时保留比较属性和基准页，替换待测入口及记录目录。

## 从样本交付到完整说明书

输入留存、独立读图和手记是中间交接。继续完成分支契约、参考图与逐件报价、实际生成、工作面校正、动作对位、浏览器检验、设计对照和离线打包。额度等待只暂停依赖扣款的任务。将通过的资产用到清点弹窗和装配过程的同一实例，交付记录列出逐件来源、用到的网格或材质、修形和实测范围。

## 图鉴、成品照与收藏

1. 用装配台验收过的成品网格拍封面。Blender 使用透明底、正交三分之四视角、中性主光和轮廓光，保留材料本色。目录里的纸色或彩色衬底放在图像后面，检查红瓦、蓝窗、松木纹和深色桌腿在成品尺寸下是否清楚。可见形态不同的路线各出一张收藏照。现有相机与灯光见同目录 render_covers.py。
2. 目录沿用纸色、墨蓝、陶土色、宋体标题和细分隔线。作品条目呈现真实成品、产品名、拼装规模和操作入口。全部作品保留主次编排。我的收藏显示已入藏的作品和首次完成日期。
3. 播放或拖动使某个必做步骤到达终点时，由播放器发出可取消的 academy:step-complete 事件。detail 包含作品 id、从 0 起的 step、必做步骤总数 total，多路线产品另传 path。预览成品和选做调节不计入进度。collection.js 按作品和路线分别累计、去重，当前路线齐全后展示成品照和入藏印章。首次入藏保留该路线的样式和日期。用户可以返回成品视角旋转查看，也可以从目录续拼最早缺少的一步。
4. 三个播放器加载同一份 collection.js 和 collection.css，Mac 离线启动器固定使用 127.0.0.1:4184，使同一浏览器重开后仍能看到收藏。替换其他产品时，由该播放器提供步骤及成品视角，沿用共享藏品页。
5. 发布前用干净浏览器从目录实际走完流程。检查空收藏、最后一步跳步、重复播放、跨路线、齐步入藏、重新打开后的记录、减少动态效果和窄屏布局。桌面目录和真实入藏页各保留一张截图。

发布时逐页核对图鉴、小屋、家具说明书和收藏页的字标、页面标题及页脚。品牌统一为「拼装工坊」，「海边小屋」等名称用于标识具体作品。

纸模成品采用独立观赏视图。按实际零件投影包围盒居中构图，收起零件板和步骤面板，让画布保留旋转、缩放和返回装配操作。首次入藏在画布上方显示可打开的收藏卡。用桌面与手机视口检查屋顶、围栏和底座均完整入镜。
